# Ecosistema Educativo sobre el Método de Falsa Posición (Regula Falsi)
**Universidad de Santander (UDES) - Facultad de Ingeniería de Software**
**Asignatura:** Métodos Numéricos

## Descripción del Proyecto
Ecosistema educativo integral diseñado para la enseñanza, práctica y aplicación del método de Falsa Posición en la resolución de problemas de ingeniería de software (optimización de recursos en infraestructura cloud y microservicios).

## Contenido del Repositorio
* `falsaposicion.py`: Motor matemático central e implementación del algoritmo.
* `test_falsaposicion.py`: Pruebas unitarias automatizadas.
* `ESTADO_DEL_PROYECTO.md`: Registro detallado del estado de avance.
* `PROMPT_CONTINUACION.md`: Instrucciones para la continuidad en sesiones futuras.

## Requisitos y Ejecución
* Python 3.8 o superior.
* Para ejecutar las pruebas unitarias:
  ```bash
  python test_falsaposicion.py
  ```
